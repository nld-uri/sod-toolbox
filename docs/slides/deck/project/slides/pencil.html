The decomposition

One real symmetric pencil, smoothest coordinates first

  • Rows of X are time samples, columns are channels.
  • Each μ is the mean-square frequency of its coordinate; the smallest comes first.
  • Options change only how the covariances are formed: derivative, step, lag, centring, rank.

Nonlinear Dynamics Laboratory · SOD toolbox

Covectors psi are normalised so that psi^T Sigma_x psi = 1. Smooth coordinates q = X Psi then have unit variance, smooth modes Phi = Sigma_x Psi satisfy Psi^T Phi = I, and X = q Phi^T on the data subspace. The smooth orthogonal values are lambda = 1/mu. Introduced for mode identification by Chelidze and Zhou (JSV 2006) and for random excitation by Farooq and Feeny (JSV 2008).
